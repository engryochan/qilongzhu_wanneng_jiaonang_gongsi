## 三、計量與數值的統一口徑

依據[BIPM SI手冊](https://www.bipm.org/en/publications/si-brochure)及[NIST SI單位](https://www.nist.gov/pml/special-publication-330/sp-330-section-2)。以下為審核公式，不是本機量測或裝置設計驗收。

| 量 | 口徑 | 常見混淆及核對要求 |
|---|---|---|
| 頻率 | f：Hz；角頻率ω：rad/s，ω=2πf | 40Hz不是40rad/s；聲光、EEG、電流的40Hz不可視作同一機制 |
| 能量／功率 | E：J；P：W=J/s | 峰值、平均、脈寬、重複率分開。重複脈衝P平均=每脈衝能量×重複率 |
| 電氣 | V、A、V/m；波形、DC偏置、峰峰值／RMS分開 | 純零偏置正弦才有Vrms=Vpeak/√2；一般功率為平均v(t)i(t)，不總等於VrmsIrms |
| 流體 | 密度kg/m³、速度m/s、流量m³/s、壓力Pa、推力N | L/min換m³/s須除60,000。N/kW是推力功率比，不是無量綱效率 |
| 運動與引力 | g為加速度，G為萬有引力常數 | 載具加速度造成的負荷、旋轉訓練與新增引力源分開 |
| 聲學／光學 | dB須附參考值；lux與W/m²分開 | 光譜、頻寬、距離、接收面積及響應函數不能省略 |
| 研究準確率 | 分母、樣本、任務、時窗與基線明示 | 受試者數、電極接點數、試次數不是同一分母；無法直接比較跨研究百分比 |
| 證據數 | 每個來源、研究、試驗、隊列及監管事件分別分組 | 60登錄列不等於60篇獨立研究；目前50個人工來源群也不是50項獨立研究 |

**引力量級算例**：若將新增引力源理想化為點質量、距離0.1m、目標9.80665m/s²，使用G≈6.67430×10⁻¹¹m³kg⁻¹s⁻²，M=gr²/G≈1.4693×10⁹kg，Mc²≈1.3206×10²⁶J。這是特定牛頓模型下的需求及靜質能等價，**不是證明需要實際耗費該能量，也不是一般人工重力不可能定理**。相對於全球能耗的「幾個數量級」須另附同年能源統計與能源範圍；本輪不採用未有分母的比較。

## 四、採信、來源獨立性與狀態

- `SOURCE_UNAVAILABLE`：工具未取得足夠內容。不可推論「造假」「沒有研究」或「已經核對」。
- `METADATA_ONLY`／`PUBLISHER_INDEX_ONLY`：僅入口、題名、日期或索引摘要；不能當成完整論文品質審查。
- `ABSTRACT_SCOPE_CHECKED`：已對照摘要所支持的研究對象與結論範圍；不表示重算原始資料。
- `REGULATORY_SCOPE_CHECKED`：只對照指定適應症和文件日期；後續標籤須另查，不等於全球通用許可。
- `RELEASE_CHECKED`：核到官方版本；不表示已安裝、跑通、取得付費模組或驗證本機相容性。
- 重複與相關來源：保留追溯，不累加為獨立複驗。綜述與其所含原研究亦需防止重複計數。

多模型獨立探索後做覆蓋聯集，再按證據採信。共享原始來源的多家回答不是多份證據；出現新線索時進待核清單，不因少數來源而丟棄，也不自動升格。

## 五、優先續核清單

1. `SOURCE_UNAVAILABLE`四列及全文未取得的光學、器官晶片和臨床綜述；核題名、年份、作者歸屬、是否更正／撤稿、研究設計及原始數值。
2. 歷史稿中的Neuralink／北腦／博睿康例數和批准狀態、Meta Brain2Qwerty數值、Tesla／Unitree出貨與部署數、CL1／FinalSpark價格與示範；本輪不採信未逐條取證的數字。
3. 145位人物逐人身份與貢獻、110技能原作章回與科學對照、14類學派原始史料；本輪僅完成種子完整對賬。
4. 法人、國企／民企、國籍、操作系統、硬體型號、授權與版本相容性仍需獨立文件，不能從首頁或品牌名推定。
5. 先以可量測、可重算且有原始資料的問題推進；世界第一、最頂尖、完整涵蓋等比較必須先有母體、基準日、同口徑性能與檢索策略。

## 六、可重現文件與驗收

`audit_project.py`生成逐檔掃描、候選行索引和摘要；候選行可能同時含多個斷言、標題或程式碼，不能當成語義斷言總數。`integrate_audit.py`依保存的來源回執回填CSV，重跑不是再次外部查證。三份種子CSV保留原資料的相對路徑、記錄序號與SHA-256。

現行雜湊獨立寫在`交付現況_SHA256_20261016.csv`，不把JSON自身雜湊塞回自身。舊驗收JSON中的歷史雜湊移至歷史區，不作現行交付驗收。所有不適用的網頁互動、SQL與臨床復現檢查均不宣稱PASS。
